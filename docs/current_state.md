> 漢字版（explanation_advanced）は現状 **りか68問のみ**。さんすう・こくごの漢字版は今後の課題（NULLの間はひらがな版にフォールバックされるので無害）。

### 解説の書き方ガイド（さんすう・りかで確立）

**ていがくねん版（explanation）＝ ひらがな主体**
- **標準語のやさしいふつう語**（「〜よ」「〜だよ」「〜！」）。です/ますでも**関西弁でもない**（※ちゃぴの口調が漏れやすいので注意）
- **その問題が ていがくねんモードで見せている以上の漢字を足さない**（りかは問題が全ひらがな→解説も完全ひらがな。こくごおくりがなは問題が漢字を見せる→解説も漢字でOK）
- 答えだけでなく**解き方／なんで？の型**を入れる（さんすう:「10のまとまり」「九九の逆」「通分」等／りか:理由・仕組み・おぼえかた）
- 文章題・具体物は末尾に絵文字を1個程度（🍎🌈🧲など）

**こうがくねん版（explanation_advanced）＝ 漢字混じり（v0.9.6〜）**
- 漢字レベルは `question_advanced` と同じ（**小学漢字〜6年は漢字**）
- **中学漢字（窒・浮・肝・蒸・惑・振・範・昆 など）はひらがなで残す**（解説は"読める助け舟"のため）
- 中身はひらがな版と同じ内容を漢字化したもの

**配管・表示先**
- 配管: `questionLoader.js` `dbToAppFormat` → `explanation` ＋ `explanationAdvanced`（両方）
- 表示先: `LearningScreen.js`（不正解時のみ💡黄色カード）。`displayMode === 'kanji' && explanationAdvanced ? 漢字版 : ひらがな版`（**NULLならひらがなにフォールバック＝安全**）

## 🔧 開発ルール

- version.json / APP_VERSION / package.json は同時更新
- **DBコンテンツのみの追加（解説など）はバージョンを上げない**（コード変更がないとUpdateBannerが誤通知するため）
- `dbToAppFormat`（questionLoader.js）がDB→アプリの唯一の変換ポイント
- DDLは`Supabase:apply_migration`、DMLは`Supabase:execute_sql`
- JSONB列は`'[...]'::jsonb`明示キャスト必須
- 日本語SQL UPDATEは8〜10行バッチが安定（CASE WHEN方式が安全）
- **changelog.htmlは public/ と docs/ の2箇所に配置。必ず両方同時更新し、`diff` で一致確認すること**
- のんはコードに不慣れ→修正はちゃぴ担当、ファイルで渡す
- SubjectMenuScreen: SUBJECT_CATEGORIESにカテゴリ追加で拡張可能
- 解説: `explanation`（ひらがな）/ `explanation_advanced`（漢字）の2カラム（共にnullable）。こうがくねんモードは漢字版、NULLならひらがな版にフォールバック。書き方は「解説の書き方ガイド」参照
- **こうがくねんモードがあるUIには、解説も漢字版を用意するのが原則**（ひらがな解説だけだと漢字が読める子には逆に読みにくい）
